Data Transparency

Dữ liệu thực tế và dữ liệu minh họa

Dashboard cố ý phân biệt rõ dữ liệu lấy được từ container với thông tin chỉ mang tính minh họa cho đồ án.

Dữ liệu thực tế
  • Git Commit SHA: Được đọc từ file được tạo lúc Docker build.
  • Web Server: Nginx.
  • Container: Ứng dụng hiện tại đang chạy trong Docker.
  • Dashboard: Được phục vụ bởi Nginx trong container.
Dữ liệu minh họa
  • AWS Region: Hiển thị theo kiến trúc dự án, không tự nhận là dữ liệu runtime.
  • ECR Status: Nội dung mô tả luồng triển khai, không phải truy vấn trực tiếp AWS API.
  • Infrastructure: Các thành phần Terraform được giới thiệu ở mức kiến trúc.
  • Runtime Metadata: Không được giả lập là dữ liệu IMDSv2 thật.

🔐 Lưu ý bảo mật về EC2 IMDSv2

Trình duyệt của người dùng không nên và không thể được xem như một ứng dụng server-side có quyền truy cập trực tiếp EC2 Instance Metadata Service. Dashboard này không giả vờ truy vấn endpoint IMDSv2 để lấy metadata của EC2. Nếu hệ thống cần runtime metadata, nên thực hiện việc truy vấn ở phía server-side, giới hạn dữ liệu được trả về và tuyệt đối không expose credential, token hoặc thông tin nhạy cảm cho trình duyệt.


Ví dụ kiến trúc an toàn: Browser → Application Server → IMDSv2. Application Server chỉ trả về những trường cần thiết như environment hoặc instance identifier đã được kiểm soát, thay vì chuyển tiếp toàn bộ metadata.
